# Tools

The server gives your assistant these tools. The assistant chooses and calls them. You do not call
them yourself.

| Tool                       | Endpoint                                                                            | What it gives                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| -------------------------- | ----------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `listActivities`           | `/activitylist-service/activities/search/activities`                                | a compact summary of each activity: the Garmin type key and the FIT SDK sport name, km, moving and elapsed time, pace, HR, cadence, ascent, HR-zone seconds, Garmin training load and training effect, intensity minutes, race flag, best efforts, power, running form, run/walk segments, swim SWOLF, lengths and strokes. `raw=true` gives the full JSON.                                                                                                                                                   |
| `getActivity`              | `/activity-service/activity/{id}`                                                   | summary, metadata and segments by type                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `getActivityLaps`          | `/download-service/files/activity/{id}`                                             | laps from the .FIT file: km, time, pace or speed, HR, cadence, ascent, power and intensity                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `getActivitySets`          | `/download-service/files/activity/{id}`                                             | strength sets from the .FIT file: exercise, movement category, primary and secondary muscles, reps, weight (kg), set time and the rest after the set. The empty set that the watch adds at the end of a workout is not shown                                                                                                                                                                                                                                                                                  |
| `getActivityWorkouts`      | `/activity-service/activity/{id}/workouts`                                          | the planned workout that the activity followed: steps with intensity, duration, target, exercise and notes. Null fields are left out; an empty list means no planned workout                                                                                                                                                                                                                                                                                                                                  |
| `downloadActivityFit`      | `/download-service/files/activity/{id}`                                             | saves `{id}.fit` in the `fit` folder of the data folder. The server downloads each file one time only.                                                                                                                                                                                                                                                                                                                                                                                                        |
| `getHrvRange`              | `/hrv-service/hrv/daily/{from}/{to}`                                                | HRV during the night                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `getDailyHeartRate`        | `/wellness-service/wellness/dailyHeartRate`                                         | the heart rate of a day, with the resting HR                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `getSleep`                 | `/sleep-service/sleep/dailySleep`, `/sleep-service/sleep/dailySleepSummariesByDate` | one compact row per night: bedtime and wake, hours of sleep and of each phase, the sleep score, the sleep need, heart rate, SpO2, respiration and sleep stress. One night, or up to 14 nights with `fromDate` and `toDate`: a night without sleep data has only its date. The date is the morning after the night. `raw` gives Garmin's JSON.                                                                                                                                                                 |
| `getWeight`                | `/weight-service/weight/range/{from}/{to}`                                          | the weight and body composition of each day in a range, its average, and the weights just before and after it. `includeAll` gives every entry of a day                                                                                                                                                                                                                                                                                                                                                        |
| `getBodyBattery`           | `/wellness-service/wellness/bodyBattery/reports/daily`                              | how Body Battery charged and drained each day, its readings, and the events that changed it, for up to 14 days with `fromDate` and `toDate`                                                                                                                                                                                                                                                                                                                                                                   |
| `getHeartRateZones`        | `/biometric-service/heartRateZones/v2`                                              | the HR zones in Garmin Connect                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `getFitnessAge`            | `/fitnessage-service/fitnessage/v2/{date}`                                          | fitness age against actual age, and its components                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `getDailySummary`          | `/usersummary-service/usersummary/daily`, `/usersummary-service/v2/dailysummaries`  | steps, stress and body battery, for a day or up to 14 days with `fromDate` and `toDate`. The range answer has Garmin's v2 field names.                                                                                                                                                                                                                                                                                                                                                                        |
| `getDashboardData`         | the endpoints above                                                                 | all the data of the dashboard in one call. It keeps a local cache and asks Garmin only for new days. The result starts with `digest`: the server's totals for the period and for each week. Each activity is on its own line. `sync.failedSections` lists the sections that Garmin did not give (`zones`, `fitnessAge`, `hrv`); they show as n/a. `workouts` = true also gives the laps of the runs of each name that repeats: the last 8 (downloaded once), and older ones whose .FIT file is already saved. |
| `writeDashboard`           | the endpoints above                                                                 | writes the dashboard page (default `garmin-dashboard.html` in the data folder) and gives a short digest of the data for the coach notes. An update changes only the data of the page. A replaced page is kept as `.bak`. `settings` set the title, the sports, the data, the languages, the themes and the workout comparison of the page; `preview` writes nothing and gives the activities of each board and the settings of the page.                                                                      |
| `editDashboard`            | none                                                                                | changes the layout of the dashboard page, adds or removes custom widgets, and adds and removes languages. Without arguments, it gives the layout, the widget catalogue and the guide for a custom widget.                                                                                                                                                                                                                                                                                                     |
| `showDashboard`            | the endpoints of `writeDashboard`                                                   | shows the dashboard page in the chat, in Claude Desktop and other clients that show MCP Apps, with new data. It uses the layout, custom widgets, languages and settings of the saved page, or the preset page when there is none. It writes no file and has no coach notes. The data goes only to the page; the assistant gets the digest. See [Show the dashboard in the chat](dashboard.md#show-the-dashboard-in-the-chat).                                                                                 |
| `scheduleDashboardRefresh` | the endpoints of `writeDashboard`, at the scheduled time                            | turns on, changes or stops the automatic update of a dashboard page, with a cron expression that the assistant makes from your words. Two updates must be at least 1 hour apart. It adds one job to the scheduler of the computer. The update removes the coach notes. Without arguments, it gives the schedule, the next three updates and the pages. See [Update the dashboard on a schedule](dashboard.md#update-the-dashboard-on-a-schedule).                                                             |
| `garminGet`                | all other GET endpoints                                                             | a relative path and a query string                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |

Dates use the format `yyyy-MM-dd`. The API reference does not always give the names of the query
parameters. If an endpoint answers 400, the assistant can use `garminGet` to try a different name.
`activityType` takes a parent type, such as `running` or `cycling`, or a subtype, such as
`trail_running`. Garmin accepts a subtype only as `activitySubType`: when it refuses the type
(HTTP 400), `listActivities` asks again with the subtype. When Garmin refuses both, it asks for
the last 200 activities and keeps those whose type key is exactly `activityType`. `names` keeps
the activities whose name contains one of the names, ignoring case. For this, `listActivities` asks
for the last 200 activities of the window, then applies `limit`. `garminGet`
decodes the query string before it sends it, so an encoded value such as
`calendarDate=2026%2D10%2D24` also works.
API reference: <https://developer.garmin.com/gc-developer-program/personal/swagger-docs/>

The Personal API does not have these Garmin Connect data, and their endpoints answer 404:

- VO2 max, training status and readiness, race predictions and personal records;
- gear and activity weather;
- endurance and hill score, lactate threshold and exercise sets.

When the dashboard needs one of these values, it calculates an estimate and labels it.

## The data folder

The data folder has:

| File                                        | Content                                                                |
| ------------------------------------------- | ---------------------------------------------------------------------- |
| `fit/{id}.fit`                              | the original .FIT files. The server downloads each file one time only. |
| `exercises.json`                            | the exercise catalogue of Garmin, for the muscles of each exercise     |
| `dashboard-cache.json`                      | the dashboard data of the last calls                                   |
| `widgets.json`                              | your custom widgets: every dashboard page gets them                    |
| `auto-refresh.json`                         | the automatic update: its cron expression, its pages and the last run  |
| `auto-refresh.cmd`, `auto-refresh-task.xml` | Windows only: the script and the task of the automatic update          |

The server writes its log to `~/.cache/garmin-personal-mcp/garmin-personal-mcp.log`. When the log
is larger than 1 MB, the server moves it to `garmin-personal-mcp.log.1` and starts a new log.

The automatic update writes one line for each page to `~/.cache/garmin-personal-mcp/refresh.log`.
Its job is outside the data folder: `~/Library/LaunchAgents/com.indaco.garmin-personal-mcp.refresh.plist`
on macOS, a line that ends with `# garmin-personal-mcp refresh` in your crontab on Linux, and the
task `garmin-personal-mcp refresh` in Task Scheduler on Windows.
