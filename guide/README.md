# Guide

The guide tells how to use garmin-personal-mcp after the
[quick start](../README.md#quick-start). Each page is about one topic.

## Your data

- [Tools](tools.md): each tool, its Garmin endpoints, and the data that the Personal API does not
  have. The data folder and its files.
- [How it works](how-it-works.md): how the client starts the server, the API key and the access
  token, laps and sets from the .FIT files, and the caches.

## The dashboard

- [The training dashboard](dashboard.md): make and update the page, update it on a schedule, show
  it in the chat, boards, layout, themes, units and page settings.
- [Widget catalogue](widgets.md): every built-in widget, with what it shows and how it calculates.
- [Custom widgets](custom-widgets.md): make a widget from your own idea.
- [Languages](languages.md): the built-in languages, and how to add a language.
- [Presets or freeform](presets.md): why the server writes the page from a template, with the
  measurements.

## Help

- [Problems and solutions](troubleshooting.md): the common problems, the log files, and commands
  that test the key and the server.
- [Security](../SECURITY.md): how the server protects your data, and how to report a
  vulnerability.
