# garmin-personal-mcp

**Your Garmin training in Claude, through the official Personal API. Read-only, nothing to
install.**

> Work in progress: a TypeScript port of [indaco/garmin-mcp](https://github.com/indaco/garmin-mcp).
> The tools, prompts and setup are documented when the port is complete.
