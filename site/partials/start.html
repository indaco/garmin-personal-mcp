start in three steps.

You need {{node}} and a Garmin Connect account with access to the Personal API.

1

create a personal API key

Open the API key page in Garmin Connect web, select Create Key and choose the expiry. Garmin shows the key only one time. Save it in a file that only you can read: 

mkdir -p ~/.config/garmin-mcp
nano ~/.config/garmin-mcp/api-key
chmod 600 ~/.config/garmin-mcp/api-key

You can also give the key in GARMIN_PERSONAL_API_KEY.

2

connect your client

Settings → Developer → Edit Config. Add a top-level mcpServers key, then quit Claude Desktop fully and start it again. 

{
  "mcpServers": {
    "garmin-personal": {
      "command": "npx",
      "args": ["-y", "{{package}}"]
    }
  }
}

This command adds the server to all your projects.

claude mcp add garmin-personal --scope user -- npx -y {{package}}

The first npx download can take longer than the default start time. In ~/.codex/config.toml, set startup_timeout_sec = 60. 

codex mcp add garmin-personal -- npx -y {{package}}

Other stdio MCP clients: command npx, arguments -y {{package}}.

3

ask your assistant

Start a new chat and ask about your training. To make the dashboard, run the training-dashboard prompt. 

List my last 5 activities, with pace and heart rate.

The server stores the .FIT files and the dashboard in ~/workspace/garmin-data. Set GARMIN_DATA_DIR to use a different folder.
